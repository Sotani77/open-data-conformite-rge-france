La sélection conserve toutes les communes du référentiel API Geo dont le nombre d'établissements de travaux RGE actifs rattachés est exactement nul. Elle inclut aussi les communes sans dénominateur logement connu : celles-ci restent identifiables dans les colonnes source_logements et nb_logements. Aucun effectif nul ne résulte du remplacement d'une valeur manquante. La synthèse fournit, pour chaque département, le nombre de communes de référence, le nombre sélectionné, leur part et les sommes de population et de logements connues. Ces sommes ne mesurent pas des personnes privées d'accès à un artisan. L'absence d'implantation recensée n'est ni une preuve d'absence de professionnels intervenant sur place, ni une mesure de pénurie.
